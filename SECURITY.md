# Security Policy

## Reporting Security Issues

OpenAI takes security seriously. If you believe you have found a security
vulnerability in this Google Tag Manager template, please report it through
OpenAI's [Coordinated Vulnerability Disclosure Policy](https://openai.com/policies/coordinated-vulnerability-disclosure-policy).

Please do not report security vulnerabilities through public GitHub issues.

For questions about reporting a vulnerability, contact disclosure@openai.com.
