# Security Policy

## Reporting Security Issues

This repository is a community-maintained fork and is not operated by OpenAI.

- Vulnerabilities in the OpenAI Pixel SDK (`oaiq.min.js`) or in OpenAI services:
  report them through OpenAI's
  [Coordinated Vulnerability Disclosure Policy](https://openai.com/policies/coordinated-vulnerability-disclosure-policy).
- Issues in this Google Tag Manager template: open a private security advisory
  on this repository on GitHub, or contact the maintainer through the GitHub
  profile linked in `metadata.yaml`.

Please do not report security vulnerabilities through public GitHub issues.
